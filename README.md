### 🧠 [VidMind AI](https://github.com/Suryakant2112/vidmind-ai)
Turns **YouTube lectures** into structured summaries, detailed study notes and grounded **Q&A** — powered by Retrieval-Augmented Generation. Every answer links back to the exact timestamp in the video.

- 🎬 Auto transcript extraction + paste-a-transcript fallback
- 🔎 Semantic chunking → FastEmbed → **Qdrant** vector search
- 🔁 LLM fallback chain: Groq → Groq → Gemini
- 🌗 React notebook-style UI, light/dark mode, mobile-ready

### 📈 [Crypto Watchlist](https://github.com/Suryakant2112/crypto-watchlist)
A **real-time crypto terminal** that streams live 24h ticker data for *every* Binance Spot pair over WebSocket into a dense, virtualized table.

- ⚡ 3,000+ symbols updating every second, still buttery smooth
- 🟢🔴 Price-flash on every tick, sorting, `/` to search
- 🔌 Auto-reconnect with backoff, offline detection, watchdog
- 📱 Responsive down to phone width, zero extra runtime deps

### 👕 [Project VASTRA](https://github.com/navneet-cerecode/ProjectVASTRA) — *Virtual Apparel Simulation for Try-on & Realistic Augmentation*
A **deep-learning virtual try-on pipeline** built on HR-VITON: give it a person's photo and a garment, and it renders the outfit on the person. Modular preprocessing (OpenPose keypoints, segmentation, cloth masks, warping) feeds pre-trained models for inference — ready for research experiments and hackathon demos.
