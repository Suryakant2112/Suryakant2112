### 📈 [Crypto Watchlist](https://github.com/Suryakant2112/crypto-watchlist)
A **real-time crypto terminal** that streams live 24h ticker data for *every* Binance Spot pair over WebSocket into a dense, virtualized table.

- ⚡ 3,000+ symbols updating every second, still buttery smooth
- 🟢🔴 Price-flash on every tick, sorting, `/` to search
- 🔌 Auto-reconnect with backoff, offline detection, watchdog
- 📱 Responsive down to phone width, zero extra runtime deps

### 👕 [Project VASTRA](https://github.com/navneet-cerecode/ProjectVASTRA) — *Virtual Apparel Simulation for Try-on & Realistic Augmentation*
